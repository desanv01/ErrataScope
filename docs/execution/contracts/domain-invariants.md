# Domain invariants — revision 1, binding

1. ErrataScope owns manufacturer-advisory interpretation, scoped applicability, evidence review, and changed-baseline impact.
2. VerifForge retains its entire planned execution, investigation, simulation, verification, reduction, and repair scope. No firmware runner, simulator, model checker, patch generator, or behavioral test generator enters this application.
3. Source content is data. Never execute source instructions or model-generated code.
4. A missing fact is unknown, not false. A failed extraction is unsupported/unprocessed, not not-applicable.
5. Exact component identity, silicon revision, board/build/profile scope, and identity evidence remain distinct.
6. Draft model output is provisional. Schema and citation checks do not establish semantic correctness.
7. Acceptance pins exact rule/fact/source versions. Later edits create versions, not silent replacements.
8. Source coverage is explicit. Selected-entry coverage is not a whole-device safety claim.
9. Applicability, workaround documentation, requirement consistency, human disposition, and freshness remain separate.
10. Conflicts require accepted evidence in the same relevant scope. Do not invent electrical/firmware behavior to complete an argument.
11. Dependencies include missing selectors and skipped branches. New-entry detection uses product identity subscriptions as well as old dependency edges.
12. Historical assessments remain reproducible against their selected baseline. A new baseline reopens review without rewriting history.
13. Model retries and cached outputs retain provenance. Never represent cached or manual output as a live model result.
14. Project authorization applies to data, jobs, artifact links, and exports, even with privileged server credentials.
15. Manufacturer document access does not imply permission to redistribute it. Public fixtures need appropriate provenance/rights.
16. No unsupported accuracy, safety, certification, or market novelty claims.

Changes require an explicit Codex decision consistent with human instructions. Workers report a conflict rather than editing this contract.
