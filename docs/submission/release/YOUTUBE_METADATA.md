## Description

ErrataScope is a cited manufacturer-errata review workspace built by Desan Vasu for the Nebius x NVIDIA Global AI Hackathon 2026 — Best Apps and Agents Track.

Inspect the manufacturer source beside an AI interpretation, follow claims to their citations, preserve unknown information, record a human review, and export the evidence as JSON or Markdown.

NVIDIA NEMOTRON + NEBIUS TOKEN FACTORY
The backend uses nvidia/Nemotron-3.5-Super-VL through the Nebius Token Factory inference API to interpret selected manufacturer excerpts into a structured, cited draft. Hosted inference lets the application use the NVIDIA model through an API without preparing a local GPU inference server.

This actual desktop-app demonstration replays a recorded result from an earlier real provider request. Loading the free test build makes no fresh inference call. The separate synthetic/offline missing-information example is clearly labeled.

DEMONSTRATED SCOPE
Manufacturer source: STMicroelectronics ES0620 Rev 5, selected sections 2.2.18 and 2.2.5. Coverage is limited to 2 supported entries out of 53 detected; the inventory is incomplete. Human review records observations and does not establish device applicability or create an accepted executable rule.
