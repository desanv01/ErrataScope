# Demo script — under three minutes

1. **Open the workspace** at `http://127.0.0.1:18080/` using `scripts/submission/start.ps1`. Point out the dark workspace, selected-source navigator and light source pane beside the review pane.
2. **Recorded live result.** Show the header's **Recorded live Nemotron result** label. Note the project/context is ES0620 Rev 5, the real extraction covers selected entries 2.2.18 and 2.2.5, and the provider request ID/usage are the recorded values. State explicitly: this is a recorded result, not a new call.
3. **Inspect a citation.** Select entry 2.2.18, then click the page chip beside a claim. The light pane jumps to the actual located excerpt with physical page/printed label, section and anchor key.
4. **Show what is unknown.** Point to the amber **Unresolved information** panel (affected device, exception) and the coverage card: 2 selected/supported of 53 detected entries; inventory incomplete; unselected entries are not assessed.
5. **Review.** Enter a short note. Click **Review draft**. Show the reviewed badge and the new history row. Explain that this is human acknowledgement, not an accepted executable rule.
6. **Concurrency (optional).** Change the revision in another request or tab; attempting another decision shows a stale-conflict message rather than overwriting.
7. **Export.** Click **Export Markdown** (or JSON) and open the downloaded summary. It contains the source hash/URL, recorded provenance, claims/citations with page metadata, unresolved fields, coverage and review history.
8. **Synthetic example.** Switch the case selector to **Synthetic / offline example**. State that it is an original synthetic missing-information case, not a live omission pass and not manufacturer applicability.

Do not show facts/applicability controls; they are intentionally absent. Do not imply full-document coverage, certification or hosted production acceptance.
